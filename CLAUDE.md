# Проект: <название>

## Стек

- Монорепо, npm workspaces: `backend/`, `frontend/`, `packages/shared/`.
- Бэкенд: Node 20+, TypeScript, Fastify, Prisma, PostgreSQL.
- Фронтенд: React + TypeScript + Vite.
- Тесты: Vitest.

## Команды

- Установка: `npm ci` (первый раз — `npm install` + закоммитить лок)
- Полная проверка: `npm run verify` (из корня)
- Бэкенд dev: `npm run dev:backend` | Фронт dev: `npm run dev:frontend`
- Миграции: `npm run db:migrate` (только по явной просьбе)

## Правила

- Не добавляй зависимости без явного разрешения.
- Не меняй `package-lock.json` вручную.
- Следуй форме соседнего модуля; новые паттерны не вводи.
- `any` запрещён. Непонятный тип — `unknown` + проверка.
- Импорты типов — через `import type`.
- Промисы всегда awaited или явно `void` с комментарием.

## Запрещено

- `git push`, `git reset --hard`, `--force`, `git checkout --` — никогда.
- Трогать `.env`, секреты, CI-конфиги без спроса.
- Править применённые миграции. Только новые.
- Правки вне текущей спеки. Нужен файл вне плана — стоп, спроси.
- Конкатенация строк в SQL. Только параметризованные запросы Prisma.

## Definition of Done

1. `npm run verify` зелёный.
2. Критерии приёмки из `spec.md` выполнены.
3. Отчёт: что изменено, где, почему. Без «готово» до зелёного verify.

## SDD

Источник истины — `specs/`. Порядок: spec.md → plan.md → tasks.md → код.
Код не начинается, пока `tasks.md` не согласован.
Шаблоны и правила: @docs/sdd.md
