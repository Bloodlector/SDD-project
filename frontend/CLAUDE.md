## Структура

- `src/features/<feature>/` — компоненты, хуки, api-вызовы фичи.
- `src/components/` — только переиспользуемое, без знания о фичах.
- `src/api/` — единственное место, где живёт fetch.

## Правила

- Никаких fetch/axios в компонентах. Только через `src/api/`.
- Типы запросов/ответов — из `packages/shared`, не переписывать локально.
- Состояние: локальный `useState`. Глобальный стор — только по явной просьбе, не по умолчанию.
- Ошибки загрузки отображаются всегда; пустое состояние — не «вечная загрузка».

## Стиль

- Функциональные компоненты, хуки. Классовых нет.
- Не менять глобальные стили ради одной фичи.
